Cortes Factory

A private tool that publishes highlight clips to one YouTube channel: @clipesyoutubersbr.

Cortes Factory finds the best moments of long live streams from Brazilian creators who allow clips with credit, edits them into short vertical videos with subtitles, and uploads them to the channel above.

Credit to creators

Every clip shows "Credits: @creator" on screen. The description and a comment on the video link to the creator's official channel and to the original video, so viewers can find the full stream.

Who can use it

Only the owner of @clipesyoutubersbr. The tool is not offered to the public, has no user accounts, and only accesses the owner's own channel.

This application uses YouTube API Services.
