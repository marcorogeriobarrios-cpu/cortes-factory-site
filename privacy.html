Privacy Policy

Last updated: November 15, 2026

YouTube API Services

Cortes Factory uses YouTube API Services. By using Cortes Factory you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses this application

Cortes Factory is a private desktop tool. Its only user is the owner of the YouTube channel @clipesyoutubersbr. It has no public sign-up and no other users.

What information we access

  • An OAuth 2.0 token for the owner's own YouTube channel, with permission to upload videos, read the channel's basic information, and post comments.
  • The channel ID and title, only to confirm that uploads go to the correct channel.
  • The IDs and processing status of videos the tool uploads.

We do not access, collect or store information about viewers, other channels or any other YouTube users.

How we use it

The information is used only to upload clips to the owner's channel, check that each upload finished processing, and post one comment on each uploaded video linking to the original creator's channel.

How we store and share it

The OAuth token and the list of uploaded video IDs are stored only on the owner's computer. They are not sent to any server other than Google's APIs, and are not shared with, sold to, or disclosed to any third party. The tool does not use cookies or tracking on this website.

Deleting data and revoking access

The owner can revoke the tool's access at any time on the Google security settings page. Deleting the local token file removes all stored authorization data immediately; the list of uploaded video IDs is deleted together with the tool's data folder. Stored data is kept only while the tool is in use and is deleted within 30 days after access is revoked.

Contact

Questions about this policy can be sent through the About page of the channel @clipesyoutubersbr.
